## 📋 Descripción del proyecto

**Fluxa** es un Planificador de Tareas diseñado para facilitar la organización y gestión de actividades personales, académicas y laborales.

### 💡 Concepto y significado

El nombre **Fluxa** deriva del concepto de **"flow"**, que representa un flujo continuo de trabajo, organización y productividad.

La idea detrás del nombre es representar el proceso natural de avanzar de una tarea a otra, manteniendo un flujo de trabajo organizado y constante.

### 🎯 ¿Por qué Fluxa?

El nombre funciona para un planificador de tareas web porque:

- Transmite la idea de **organización sin esfuerzo**.
- Representa un **flujo continuo de trabajo y productividad**.
- Es corto, fácil de recordar y de pronunciar.
- Funciona tanto en **español como en inglés**.
- Refuerza la identidad visual y conceptual del proyecto.

Durante el **Sprint 1** se trabajó principalmente en la construcción de la estructura visual del proyecto, el diseño de la interfaz y la organización inicial de los componentes principales del planificador.
